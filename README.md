# ✈️ Airline Flight Analysis Dashboard

## 📌 Project Overview
The **Airline Flight Analysis Dashboard** is an interactive data visualization project designed to analyze airline ticket prices, flight durations, airline performance, passenger travel routes, and booking patterns. It provides meaningful insights into flight pricing and travel trends through interactive charts, KPIs, and filters.

## 🎯 Objectives
- Analyze average flight ticket prices across different airlines.
- Compare flight durations and airline performance.
- Understand the relationship between ticket prices and days left before departure.
- Identify popular source and destination cities.
- Analyze flight classes and the number of stops.
- Compare popular routes based on average ticket price and flight count.

## 📊 Dashboard Features
- **KPI Cards:** Total airlines, average ticket price, average flight duration, and average days left.
- **Airline Analysis:** Compare the number of flights and average duration by airline.
- **Price Analysis:** Explore average ticket prices by airline and number of stops.
- **Class Distribution:** Visualize the distribution of Economy and Business class flights.
- **Price Trend Analysis:** Examine how ticket prices change with the number of days left before departure.
- **City-wise Flight Analysis:** Compare flight counts across source cities.
- **Route Comparison:** Analyze popular routes, average prices, and flight counts.
- **Interactive Filters:** Filter the dashboard by airline, source city, destination city, class, number of stops, and days left.

## 🛠️ Tools & Technologies
- Power BI
- Data Visualization
- Data Analysis
- Interactive Dashboards

## 💡 Key Insights
- Compare average ticket prices across airlines.
- Identify airlines with higher flight counts.
- Understand price variations based on booking time.
- Explore popular travel routes and city-wise flight activity.
- Analyze flight duration and class distribution.

## 🖼️ Dashboard Preview
The dashboard provides a consolidated view of airline pricing, flight statistics, route comparisons, and travel patterns.

## 🚀 Conclusion
This project demonstrates the use of data visualization and interactive analytics to transform airline flight data into useful insights for understanding ticket prices, airline performance, and travel trends.
